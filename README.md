# singer-andreway
## Подборка песен (/podborka/)

Публичный репертуар поступает из локального экспортёра `andrey-local` через WinSCP в `/data/repertoire.public.json`. Клиент выбирает песни по постоянным `song_id`, фильтрует каталог и сохраняет подборку без учётной записи. Форма имени, необязательного телефона и события открывается только после выбора песен. Доступ к сохранённой подборке — по секретной ссылке с `#key=...`; номер телефона сам по себе не даёт доступа. Не показывать локальные пути MP3 в публичном JSON.

Хранилище находится в **существующем** Supabase `andrey-fitness-app` в изолированной схеме `singer`, а не в фитнес-таблицах. API: `supabase/functions/singer-request/index.ts`, Edge Function `singer-request` (`verify_jwt=false`; доступ проверяется на стороне обработчика по токену).

Для личных Telegram-уведомлений исполнителя функция использует `SINGER_TELEGRAM_BOT_TOKEN` (существующий бот Singer Andrey) и **отдельную настройку** `SINGER_OWNER_CHAT_ID` — приватный числовой chat ID владельца. Значения должны задаваться как Supabase Secrets, не в GitHub. Без `SINGER_OWNER_CHAT_ID` заявки **сохраняются**, но уведомления не отправляются; API возвращает `owner_notified:false`, и сайт сообщает об этом честно. Ссылка даёт права на редактирование: её нельзя публиковать или пересылать третьим лицам без согласия клиента.
